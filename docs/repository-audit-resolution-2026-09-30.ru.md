## Принятые границы

- Upstream MinIO и mc архивированы. Репозиторий поддерживает ограниченную standalone-сборку: отключены distributed/replication, STS/OIDC/LDAP, FTP/SFTP, S3 Select, POST-policy формы и консоль. Обычные PUT/GET, multipart и presigned-запросы сохраняются. Новые advisory требуют повторного анализа локальных исправлений; защита не восстанавливает ранее повреждённые объекты. Подробности: [границы хранилища](../docker/minio/README.md).
- Оценка полноты паспорта не является гарантией здоровья животного или репутации продавца.
- Сессия браузера остаётся Bearer/localStorage; добавлены CSP, отзыв и защита от гонок. Переход на HttpOnly-cookie требует отдельного согласованного CSRF-контракта. Хеширование защищает токены в БД, но не устраняет последствия XSS в браузере.
- Ограничитель запросов рассчитан на одну gateway-реплику. Распределённый лимит при горизонтальном масштабировании требует общего хранилища; лимиты и топология описаны в документации.
- Почта по умолчанию отключена. Для реальной доставки необходимы SMTP и ключ шифрования outbox; TLS требует домена, DNS и доступных портов. Эти внешние настройки не выполняются PR.
- Проверка восстановления использует изолированные тестовые данные. Частоту, внешнее хранилище резервных копий, ответственных и production RPO/RTO назначает оператор.

## Проверки

Локальные результаты на текущем коде:

- `gradlew build --no-daemon`: успешно; **589 backend-тестов**, 0 failures/errors/skipped (gateway 62, auth 92, common 25, listing 226, matching 74, passport 110). Включены Spotless, строгая проверка зависимостей и coverage gates.
- После окончательных изменений MinIO повторно пройдены `:passport-service:check` (**110 тестов**, formatting и coverage), настоящий API/media smoke и восстановление PostgreSQL/объектов на новом образе.
- Frontend: **43 теста**, lint без ошибок/предупреждений, production build успешен.
- Playwright: **8 браузерных сценариев** в изолированном Edge; HTTP-границы подменены fixtures. Отдельный Compose smoke проверяет настоящие сервисы.
- `npm audit` для root tooling и frontend: 0 зарегистрированных advisory; OSV: 226 JVM runtime packages, 0 совпадений.
- MinIO: **31 проверка готового контейнера** (включая multipart/presigned, query/POST/Snowball PAX и запрет FTP/SFTP), **11 тестов upstream-аудита**, сверка 27 уведомлений. Свежий govulncheck обоих Linux-бинарников: 0 уязвимых символов и импортированных пакетов; модульное совпадение GO-2026-5932 относится к неиспользуемому `x/crypto/openpgp` и явно описано в документации. JVM OSV gate дополнительно проверен **14 тестами**, включая неполные ответы и сбои API.
- Наполнение MinIO: все 20 объектов из manifest загружены; скрипт заранее проверяет наличие полного набора файлов.
- Все шесть Docker-образов приложений собраны в Linux со строгой проверкой зависимостей. Изолированный Compose-стек прошёл healthchecks и настоящий API smoke: регистрация, роли, паспорт, вакцинации, объявления, защита от поддельных заголовков, модерация, refresh/logout; файлы 1/5/10 МиБ скачаны с точным совпадением байтов, 11 МиБ отклонён с 413. Локальные лимиты JVM адаптированы к Docker VM с 2 ГиБ RAM; пользовательские сервисы не затронуты.
- Изолированный restore drill проверил SQL-маркер и точные байты объекта MinIO. `promtool` принял правила; намеренное отсутствие сервисов вызвало firing alerts. На живом стеке Prometheus видит все пять сервисов, Tempo получает трассы от каждого.
- Снимки интерфейса: [каталог](screenshots/audit-2026-09-30/catalog.png), [публичная карточка](screenshots/audit-2026-09-30/public-listing.png), [повтор сохранения](screenshots/audit-2026-09-30/edit-retry.png), [черновик](screenshots/audit-2026-09-30/draft-passport.png), [модерация](screenshots/audit-2026-09-30/moderation-retry.png).

Актуальные результаты GitHub CI и отдельного OWASP/NVD workflow доступны в [PR #185](https://github.com/hvostid/hvostid/pull/185). Локальный OWASP/NVD запуск не завершил анализ без NVD API key; OSV не подменяет этот результат. CI получает ключ из секрета репозитория и публикует собственный отчёт.

Первый завершённый NVD-анализ обнаружил 19 ложных совпадений в Java-библиотеках OpenTelemetry: пять CVE относятся к реализациям JavaScript, Go, .NET и C++, что подтверждено первичными advisory и полем `target_sw` NVD. [Узкие исключения](../dependency-check-suppressions.xml) ограничены конкретными CVE и проверенными Maven-артефактами с версиями; срок пересмотра — 31 декабря 2026. Реальная Java-уязвимость CVE-2026-45292 исправлена переходом на 1.62.0 и не исключается из проверки. Общие CPE и новые CVE не подавляются. Дополнительно пройдены 11 тестов проверки отчёта и кеша OWASP: отсутствие JSON, ошибки анализа, устаревшие данные, неполное покрытие runtime-артефактов сервисов по Maven-координатам и SHA-256, а также неверный путь H2 завершают CI ошибкой.
